# 小红书内容 Agent — 前端打磨方案

> 现状：功能完整，风格偏"内部工具"
> 目标：像 Notion / Linear 那样的主流产品质感，不像 AI 工具

---

## 一、配色重构

### 当前问题
- #ff2442 大面积使用，视觉刺激强但缺层次，长时间使用疲劳
- #f5f5f7 底灰 + 纯白卡片 = 对比度不够精致

### 新方案：小红书红降维 + 中性色体系

```css
:root {
  /* 背景层次 */
  --bg-root:     #FAFAFA;   /* 页面底 */
  --bg-raised:   #FFFFFF;   /* 卡片 */
  --bg-hover:    #F5F5F5;   /* 悬浮态 */

  /* 文字 */
  --text-primary:   #1A1A1A;
  --text-secondary: #6B6B6B;
  --text-muted:     #A3A3A3;

  /* 边框 */
  --border: #EBEBEB;

  /* 品牌色 — 小红书红只在关键节点出现 */
  --brand:        #FF2442;   /* CTA按钮、关键强调 */
  --brand-light:  #FFF0F3;   /* 标签底、选中态底 */
  --brand-hover:  #E01E3A;   /* hover加深 */

  /* 状态色 */
  --success: #16A34A;
  --warning: #F59E0B;
  --error:   #DC2626;
}
```

**用色原则**：一个页面品牌色出现不超过 3 处（1 个主按钮 + 标签底色 + logo），其他全部中性色。

## 三、自动化页面（auto.html）打磨

### 当前问题
- 表单太长，信息密度大，看起来像填报系统
- 步骤用灰底卡片堆叠，区分度不够

### 改进

**1. 表单卡片减密**

每个 card 当前有独立的标题行 + padding。改成统一紧凑节奏：

```
┌──────────────────────────────────────────┐
│  数据采集                                 │  区块标题 12px uppercase #A3A3A3
│                                          │
│  ┌ 搜索关键词 ──────────────────────────┐ │
│  │ [textarea]                          │ │  白色卡片，仅表单就够
│  ├ 话题过滤 ────────────────────────────┤ │
│  │ [textarea]                          │ │
│  └─────────────────────────────────────┘ │
│                                          │
│  ┌ 筛选条件 ────────────────────────────┐ │
│  │ 评论≥ [  ] 点赞≥ [  ] 收藏≥ [  ]    │ │  三列同行
│  │ 目标 [  ] 条                        │ │
│  └─────────────────────────────────────┘ │
│                                          │
│  AI 生成                                  │  区块标题
│  ┌ 受众 [  ]  风格 [dropdown] ──────────┤ │
│  │ 话题数 [  ]  每话题条数 [  ]  图 [  ] │ │
│  └─────────────────────────────────────┘ │
│                                          │
│  发布 & 飞书（折叠，默认收起）              │
│  ┌ [展开 ∨] ────────────────────────────┘ │
│                                          │
│  [一键执行全流程]                          │  品牌色按钮
└──────────────────────────────────────────┘
```

**2. 进度面板**

当前 5 个分步卡片灰底堆积。改成**单列时间线**：

```
  ● 采集完成 —— 共 32 条笔记              ✅ 绿色
  │
  ● AI 生成中 —— 正在分析数据…             ⏳ 品牌色脉冲点
  │
  ○ 生成配图 —— 等待中                    灰色
  │
  ○ 整理数据                              灰色
```

用 CSS border-left 连线，step-item 缩进，左边点点。去掉大块灰底背景。

**3. 输入框统一风格**

```css
input, textarea, select {
  border: 1px solid #EBEBEB;
  border-radius: 8px;
  padding: 8px 12px;
  font-size: 14px;
  background: #FAFAFA;
  transition: border-color .15s;
}
input:focus, textarea:focus, select:focus {
  border-color: #FF2442;
  background: #fff;
  outline: none;
  box-shadow: 0 0 0 3px rgba(255,36,66,.08); /* 红色微弱光晕，不是默认蓝 */
}
```

## 十二、效果对比

| 维度 | 改前 | 改后 |
|------|------|------|
| 配色 | 大面积红色 + 灰底 | 中性色为主，红色仅在关键节点出现 |
| 卡片 | 多色块混杂（红卡/白卡/按钮） | 统一白卡 + 1px border |
| 表单 | 分散在多张 card 里，滚动距离长 | 合并区块，信息密度适中 |
| 状态 | 红色 Badge = 正常（反直觉） | 绿色圆点 = 正常，红色 = 异常 |
| 排版 | 字号大小跳跃 | 22/16/14/12 四级，节奏一致 |
| 移动端 | 表格横溢出 | 表格转卡片，单列布局 |
| 代码 | 4 个文件内联 style 重复 | 提取 common.css，文件体量减 40% |

---

*改动量：提取 1 个新 CSS 文件 + 4 个 HTML 文件各调整 30-50 行，1 人半天搞定。*
*核心原则：红色做品牌点缀而非铺底色，白卡 border 做层次而非阴影，按钮 ≤2 种样式。*
